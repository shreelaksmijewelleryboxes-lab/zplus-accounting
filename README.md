# 🛡️ Z+ Secured Enterprise Accounting & Inventory Tool

A lightning-fast, ultra-secure, client-side web accounting and inventory management suite deployed instantly via GitHub Pages. Designed with an elegant dark-mode UI and protected by a master password vault.

## 🌟 Key Features

1. **🔒 Master Password Vault Protection**
   - High-security lock screen guarding all financial data, stock levels, and ledgers. Session-gated access.
2. **📦 Multi-Tier Inventory Management**
   - Granular tracking spanning **Category ➔ Sub-Category ➔ Child Sub-Category** with SKU tracking, stock counts, and unit pricing.
3. **👷 Labor & Material Variance Tracking**
   - Track labor attendance and material allocations per SKU. Automatically triggers **red-flag variance alerts** if actual material consumption exceeds standard BOM thresholds by >5%.
4. **📄 Professional Invoice Generator**
   - Clean, professional invoicing view with real-time totals, status tracking, and built-in **Print / PDF Export** capabilities.
5. **📊 Receivables & Payables Ledger**
   - Clear financial overview of total accounts receivable and accounts payable with itemized status breakdowns.

## 🚀 Tech Stack

- **Frontend Framework:** React 18 (via UMD CDN for zero-build setup)
- **Styling:** Tailwind CSS (Modern dark theme architecture)
- **Icons:** Lucide Icons
- **Hosting:** GitHub Pages (Static Web Deployment)

---

## 💻 Getting Started Locally

If you want to run or test the tool locally on your machine:

1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser (Chrome, Safari, Edge, Firefox).
3. Enter the default master password (`admin123`) to unlock the vault.
